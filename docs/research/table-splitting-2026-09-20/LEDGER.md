# Обязательства исследования

Исходный запрос: взять open-source проекты из каталога 2026-09-20, скачать
исходники локально, описать для каждого способы разбиения таблиц, сравнить
эффективность и предложить лучшие алгоритмы для Transferia.

План: инвентаризация и загрузка → аудит прямых splitter-реализаций →
аудит остальных категорий → сравнительный анализ и проектирование → проверка.
Все доступные этапы завершены. Два blocked download не препятствовали остальной
работе; они явно вынесены в итоговый отчёт. Закрытые недокументированные детали
остаются пределом знания, а не заявлением о функциональности.

Исходники: `target/research/table-splitting/sources/`, исключены из Git существующим
правилом `/target/`. Большие монорепозитории скачиваются shallow/sparse: в manifest
указывается точный состав локальных компонентов. Чужой код не исполняется.

Дополнение: коммерческие и source-available продукты исследуются по открытым
первичным описаниям; отсутствие исходников не исключает их из итоговой матрицы.

Дополнение о сроке и параллельности: пользователь разрешил субагентов и попросил
результат ориентировочно в ближайшие полтора часа. При лимите четырёх активных
агентов три независимые части делегированы: коммерческие источники;
покрытие каталога и manifest; дополнительные реализации в исходниках.
Основной агент отвечает за исходные 32 реализации, сравнительный анализ,
предлагаемые алгоритмы, сборку отчёта и итоговую проверку. Владение файлами
разделено; новые обязательства не отменяют исходные.
Все три делегированные части завершены; основной агент свёл их и выполнил
проверку. Production-код не изменён, новые бенчмарки не запускались.
